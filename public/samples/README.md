# Key Sampler sound files

Place sounds in this folder using one of these filenames:

`q.wav`, `w.wav`, `e.wav`, `a.wav`, `s.wav`, `d.wav`, `z.wav`, `x.wav`, `c.wav`

MP3 files use the same names, for example `q.mp3`. The sampler checks WAV first and MP3 second. When no matching file exists, the built-in sound for that pad is used.

## Currently mapped MP3 files

| --- | --- |

| W | `w.mp3` |
| E | `e.mp3` |
| A | `a.mp3` |

| D | `d.mp3` |
| Z | `z.mp3` |
| X | `x.mp3` |
| C | `c.mp3` |

Other filenames in this folder are not loaded by the sampler.
