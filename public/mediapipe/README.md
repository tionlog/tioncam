# Local vision assets

`selfie_segmenter.tflite` is the MediaPipe Selfie Segmenter float16 model (version 1), downloaded from Google's [model repository](https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/1/selfie_segmenter.tflite). The model runs locally in the browser to separate people from the camera background.
